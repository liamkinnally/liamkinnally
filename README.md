## Projects

- **[League Match Analysis](https://github.com/liamkinnally/league-match-analysis)** — I designed a League of Legends match-history app where players can open a match and compare two champions’ gold, CS, and experience over time. I used Java, Spring Boot, Next.js, and PostgreSQL. [Live app](https://lolmatchanalysis.app/)
- **[Lillia](https://github.com/liamkinnally/lillia-overview)** — I use Lillia to run coding tasks locally with an author agent and an independent reviewer. In the downloadable CLI alpha, I can export a Git patch after the reviewer reruns checks on the author’s revision and approves it.
- **[Aerial Inference Benchmark](https://github.com/liamkinnally/aerial-inference-bench)** — I compared PyTorch and ONNX runtimes for a YOLO26 detector trained on VisDrone. At 640 × 640, INT8 cut the ONNX file size by 69% (9.861 MB to 3.045 MB) but raised mean prediction time from 10.9 to 12.2 ms on an Apple M4 Pro CPU.
- **[NBA Player Stat Prediction](https://github.com/liamkinnally/nba-scoring-model)** — I built a Python pipeline to predict points, assists, and rebounds. On the 5,612 holdout player-games where both methods made a prediction, my points model averaged 4.841 points of absolute error versus 4.883 for the 10-game rolling average. It also underpredicted all 188 holdout performances of 30 or more points, by 13.9 points on average.
